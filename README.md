# gl下载器

面向 Minecraft 的资源下载工具，使用 Godot 4 与 GDScript 实现。软件的职责是将游戏文件、加载器、Java 运行时与社区内容下载并放置到正确位置，不包含启动游戏的功能。

## 功能

### 原版游戏

- 读取官方版本清单，完整列出版本（实测 920 项）
- 筛选：全部版本、正式版、快照、愚人节、远古版本（快照与愚人节互不重叠）
- 排序：发布时间升降序、版本号字典序
- 版本号即时搜索，支持手动刷新清单
- 下载源支持官方源与 BMCLAPI 镜像，可在设置中固定，也可自动测速择优
- 单个源不可用时自动切换至另一源重试
- 安装计划解析支持 `inheritsFrom` 继承合并，子版本 JSON 保留原始内容，同时写出父版本 JSON 与 jar
- 对仅提供 maven 坐标、缺少 `downloads` 字段的库自动合成下载信息
- 并发下载、断点续传、SHA-1 校验

### 加载器

| 加载器 | 实现方式 |
| --- | --- |
| Fabric | 拉取官方 meta，生成 profile JSON，同步父版本 JSON 与 jar |
| Quilt | 同 Fabric，使用 Quilt meta |
| Forge | 调官方安装器 `--installClient` |
| NeoForge | 多地址回退获取版本列表，调官方安装器 |

加载器版本支持自动选择（适配当前游戏版本的最新版）与手动指定。安装完成后自动校验落盘结果。

### 社区内容

Mod、整合包、资源包、光影包、数据包五类内容统一由 Modrinth 提供：

- 关键词搜索、分类筛选、排序、分页加载更多
- 项目图标异步加载，缓存上限 80 项，后台预取上限 60 项
- 版本列表按游戏版本过滤，支持自动选择最新适配版本与手动选择
- Mod 支持依赖解析与批量下载
- 整合包支持 index 文件解析、overrides 与 client-overrides 覆盖写入

各类内容默认落盘位置：

| 类型 | 路径 |
| --- | --- |
| Mod | `<游戏目录>/mods` |
| 整合包 | `<游戏目录>/versions` |
| 资源包 | `<游戏目录>/resourcepacks` |
| 光影 | `<游戏目录>/shaderpacks` |
| 数据包 | `<游戏目录>/saves/<存档名>/datapacks` |

数据包仅对单个存档生效，界面提供存档扫描与下拉选择。

### 快速安装

分步向导，逐屏确认：

1. 安装目录
2. 游戏版本（支持筛选与搜索）与自定义版本名
3. Mod 支持器及其版本
4. 附加内容（Mod、光影、资源包），双击项目选择版本
5. 确认清单与 Java 自动安装选项

安装阶段提供逐项独立进度条，涵盖原版游戏、Mod 支持器、Java 运行时与每一个附加内容，并提供暂停与取消操作。

约束条件：仅安装已选定版本的项目；无适配版本的项目标注后拒绝加入；加载器版本列表未就绪时禁止进入下一步；目标版本名已存在时阻止安装并提示改名。

### Java 运行时

- 扫描游戏目录、`JAVA_HOME`、`PATH` 及各盘常见安装位置
- 按目标游戏版本判定所需主版本号
- 缺失时可通过 Adoptium 或清华镜像安装，安装至指定目录或 `<游戏目录>/runtime`
- 下载文件执行 SHA-256 校验

### 目录与路径

- 启动时检查默认游戏目录，缺失时提示创建，并一次性生成 `versions`、`libraries`、`assets`、`mods`、`runtime`、`resourcepacks`、`shaderpacks`、`saves`、`config`、`logs`
- 默认目录可在设置中修改，留空时回退至 `%APPDATA%\.minecraft`
- 路径输入支持手动填写、系统目录选择、一键回填默认路径、全盘查找已有目录
- 当前路径缺子目录时在状态栏提示
- 路径等于默认目录时以绿色文字标识

### 进度与日志

- 原版页：原版游戏、Mod 支持器、Fabric API、附加内容各自独立进度条
- 社区内容页：按内容类型展示独立进度条
- 快速安装页：安装阶段逐项进度条，实时显示已下载字节与总字节
- 运行日志 `g-log-l.md` 生成于程序目录，最新记录置顶，正常操作绿色、报错红色、注意黄色、时间白色，条目上限 600

### 界面

- 顶部导航：原版游戏、Mod、整合包、资源包、光影包、数据包、快速安装、说明书
- 内建说明书窗口，包含文件放置规则、注意事项与常见问题
- 全局按钮动效：按下缩放回弹、圆形涟漪扩散、悬停高亮
- 启动淡入、页面切出与切入过渡
- 下载期间界面锁定，仅保留暂停与取消可用
- 窗口最小尺寸 1000×620，布局基于锚点自适应

## 目录结构

```
<游戏目录>/
├── versions/        各版本与加载器版本
├── libraries/       依赖库
├── assets/          资源文件
├── mods/            Mod
├── runtime/         本软件安装的 Java
├── resourcepacks/   资源包
├── shaderpacks/     光影
├── saves/           存档
├── config/          模组配置
└── logs/            游戏日志
```

## 项目结构

```
project.godot            工程配置
scenes/download_page.tscn  主场景
scripts/core/            下载、解析、加载器、Java、日志等核心逻辑
scripts/ui/              页面、向导、主题与动效
shaders/bg.gdshader      背景着色器
docs/                    界面预览图
```

## 设置项

| 设置 | 说明 |
| --- | --- |
| 同时下载的文件数 | 默认 16，可随时调整并立即生效 |
| 默认游戏目录 | 启动检查与默认路径按钮的基准 |
| 启动时检查默认目录 | 关闭后启动不再检查与询问 |
| 搜索模式 | 仅名称、名称与简介、翻译后搜索 |
| Java 下载源 | 自动测速、清华镜像、官方 |
| Mod 接口镜像 | 留空使用官方 Modrinth |
| 下载后校验 SHA-1 | 检测截断与损坏 |
| 强制重新下载 | 忽略本地已有文件 |
| 自动检测 Java | 切换版本时校验 Java 版本 |
| 界面缩放 | 小、标准、大 |

## 构建

需要 Godot 4.7 及以上版本。

```bash
godot --editor --path <项目目录>
```

导出配置见 `export_presets.cfg`。

## 已知限制

- 不提供游戏启动功能
- 不接入 CurseForge
- 软件内的 HTTP 请求不读取系统代理设置
- NeoForge 版本列表依赖官方 maven，网络受限时可能获取失败，此时可手动填写版本号
- 数据包按存档生效，需先选择目标存档
